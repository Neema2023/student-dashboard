# Student Admin Dashboard

## About the Project

The Student Admin Dashboard is a simple admin dashboard built using HTML and CSS.

The project demonstrates the use of CSS Grid for the main page layout and Flexbox for arranging elements inside different sections.

## Features

* Dashboard overview
* Student statistics
* Teacher statistics
* Course statistics
* Assignment statistics
* Recent students section
* Quick actions
* Responsive design
* CSS Grid layout
* Flexbox layout

## Technologies Used

* HTML5
* CSS3
* CSS Grid
* CSS Flexbox
